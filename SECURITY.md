# Security Policy

## Supported Versions

Currently, only the latest version of the Smart Drone Detection System receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project (such as prompt injection vectors in any future LLM integration, unauthorized dashboard access, or arbitrary file reads through the file uploader), please do NOT open a public issue.

Instead, please send a direct message to the repository owner at [@Krishna270704](https://github.com/Krishna270704).

We will triage the vulnerability and provide a timeline for a patch.
