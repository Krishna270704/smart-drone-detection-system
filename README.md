# Smart Drone Detection & Surveillance System

## Overview
A real-time AI-powered drone detection system using YOLO and OpenCV.

## Features
- Real-time drone detection
- Live webcam support
- Video detection
- Detection logs
- Screenshot capture
- Streamlit dashboard

## Tech Stack
- Python
- OpenCV
- YOLO
- Streamlit
- SQLite
