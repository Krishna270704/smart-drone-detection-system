# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-06

### Added
- **Streamlit Dashboard:** Interactive UI for system control and monitoring.
- **YOLO11 Detection Engine:** Custom-trained model capable of classifying Drones, Birds, and Aircraft.
- **Live Webcam Support:** Real-time object tracking utilizing ByteTrack.
- **Image & Video Processors:** Upload and analyze static assets with bounding box rendering.
- **Analytics Module:** CSV-based logging and statistical visualization of detection events.
- **Docker Support:** Fully containerized environment for Render and Hugging Face deployments.
- **Singleton Model Architecture:** Optimized memory management to prevent OOM errors during page transitions.
